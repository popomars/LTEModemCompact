# LTEModemCompact

面向 Apple Silicon Mac 的轻量 USB 蜂窝模块助手。原生 Swift + C 实现，只有苹果系统框架依赖，无第三方 Swift Package、外部后台服务或网络监听端口；可选插入启动助手随应用打包。

当前 **v0.5.0，开发预览版**：系统 ECM 联网、独立网卡页面、Wi-Fi/4G 优先级切换、网卡流量统计和独立短信收发与通知。语音尚未实现。

## 构建

需要 Apple Silicon Mac、Xcode 或具备 macOS SDK 的 Swift 工具链。包声明 macOS 13+、Swift 5.9+；目前实测环境为 macOS 26.5 / Swift 6.3.3，最低系统版本尚未实测。

```sh
git clone https://github.com/popomars/LTEModemCompact.git
cd LTEModemCompact
swift test
zsh scripts/build-app.sh
```

产物为 `dist/LTEModemCompact.app` 和独立诊断工具 `dist/ModemDiagnostics`。默认本地 ad-hoc 签名，仓库不含已公证安装包。可用 `LTE_MODEM_COMPACT_SIGN_IDENTITY` 指定自己的签名身份；签名不等于公证。

## DMG 安装包

在 Apple Silicon Mac 上执行（额外需要 Python 3；首次打包会在忽略的 `.build/dmg-tools` 中安装固定版本的 `ds-store` 和 `mac-alias`，仅用于生成 Finder 布局，不进入应用或安装包）：

```sh
zsh scripts/build-dmg.sh
```

生成 `dist/LTEModemCompact-0.5.0-macOS-arm64.dmg` 及 `.sha256` 校验文件。打开 DMG，将应用拖到 Applications，再从“应用程序”启动。更新前应正常退出旧版本；短信数据保留。

DMG 使用浅色背景、拖拽指引、固定图标位置和自制应用图标。内容仅含应用、Applications 快捷入口、安装说明及隐藏的背景与 Finder 布局文件，不打包诊断工具、开发文件或用户数据。当前预览包为本地 ad-hoc 签名，未使用 Developer ID 分发证书、未做 Apple 公证，系统可能阻止首次打开。打包脚本不会关闭或修改系统安全设置。

## 使用

1. 连接已配置 ECM 的模块，并按 macOS 提示允许 USB 配件。这个应用不替新模块自动改写 ECM、ADB 或固件。
2. 正常退出占用同一模块 AT 接口的其他客户端；同一时间只连接一只支持的模块。
3. 打开应用，从菜单栏天线图标选择“短信与网卡状态…”，顶部切换“短信”或“网卡”；菜单栏也有网卡直达入口。应用默认不弹主窗口、不占 Dock。
4. 输入号码与内容，检查段数并确认发送。模块接受后显示“已提交给模块 · 送达未确认”，需要实际收件确认才能算送达。
5. 关闭窗口后仍接收短信；菜单栏退出会停止短信后台，但不影响系统 ECM 网卡。

在短信页点击“开启短信通知”，按 macOS 提示允许；齿轮设置中可开关提示音、查看权限、打开系统通知设置或发送不计费的本机测试通知。通知中隐藏号码及正文，点击后进入短信页并选中对应记录。首次导入历史与重复读取不提醒，长短信合并完整后提醒一次；应用需保持运行，专注模式或系统横幅设置可能影响展示。登录启动仍由用户手动启用。

网卡页每约 5 秒刷新上传/下载速度及流量。本次运行从应用启动计起，累计值跨应用重启保留，确认后可清零。统计仅覆盖应用运行且 Mac 唤醒期间的模块网卡，多模块合计、不按 SIM 分账；退出、休眠或较长采样中断期间不补计。包含本地链路与协议开销，与运营商计费不等同。

网络界面上的本地 IP 只代表 USB 本地链路，不能证明 4G 互联网可用。只有点击网卡页的“优先使用”按钮才调整 Wi-Fi 与模块的先后顺序，可能触发系统管理员授权；其他服务位置及 Clash/VPN、APN、IMS 设置不变。当前选择改变的是相对优先级，不保证每条请求实际经过该接口。

## 短信行为

- 按 SIM 归档；读取前后及发送前核对 SIM，阻止换卡后沿用旧线路发送。
- 当前 SIM 的记录默认单独显示，可查看其他 SIM 和归属未核实的历史。
- 模块已有短信无法可靠推断原 SIM 时，标记为“原 SIM 归属未核实”，不提供快捷回复；首次导入不弹通知。
- 超时、断线、崩溃或部分分段成功均不自动重发；不自动删除模块短信。
- UCS2 文本发送最多 10 段，接收支持 GSM7、UCS2 和长短信拼接。暂不发送 emoji 等补充平面字符。不支持的二进制/编码保留原始 PDU，不显示为文本。
- 约每 4 秒轮询一次，另加设备响应时间；读取模块当前接收存储区，读取可能改变模块的未读标记。

## 数据与兼容性

短信保存在本机，目录权限 `0700`、文件 `0600`；没有应用层额外加密或云同步。完整边界见 [隐私与数据](docs/PRIVACY.md)。

项目早期名为 Native Modem。为保留已有数据、偏好和应用身份，更名后继续使用 `live.lepus.NativeModem` bundle ID 和 `~/Library/Application Support/NativeModem/` 数据目录。这是兼容性保留，不是额外组件；不要同时运行新旧应用。

## 插入时启动与全新 Mac 安装入口

已安装用户可在齿轮设置中选择“插入模块时：先询问 / 自动后台启动”；先把应用放入 Applications。macOS 可能要求允许后台项目，界面会显示实际注册状态。关闭该设置会撤销注册；登录自动启动是另一项独立设置。助手只在 USB 插入事件到来时短暂运行，不轮询，不发送 AT，不下载或执行远端代码；主应用已运行时不重复打开。

全新 Mac 没有预装组件，不能仅凭 ECM 接口自动弹出 GitHub 下载。`python3 scripts/build-device-portal.py` 可生成 `dist/LTEModemCompact-Install-Portal.iso`：包含离线中文指引和 GitHub Releases 快捷链接，不含可执行文件或自动运行代码。需要模块额外暴露只读 USB 存储接口后，Finder 才能看到它；用户仍需主动点击下载。**这不是已完成的设备部署：当前仅完成镜像验证和存储能力只读核实，临时接口共存与重插持久化仍待验证。**

设备临时试验脚本 `scripts/device-portal-trial.sh` 默认只检查条件；显式 `--apply-temporary` 才短暂改变 USB 组合并在 90 秒后恢复。只能在已核实固件及配置上由熟悉设备恢复流程的人操作；主应用不会调用它。详细边界见 [安装入口与插入启动](docs/DEVICE-ONBOARDING.md)。
