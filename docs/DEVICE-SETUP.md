# 新模块初始化

同为 DJI IG830 / IG832，不代表 USB 模式、内部模块或固件一致。已配置为 ECM 的设备在 macOS 允许配件后，可使用系统网卡，不必运行本应用；有效 SIM、运营商配置、信号及路由仍影响联网。

出厂网络模式为 0 的已支持模块需要一次持久配置，将 usbnet 改为 1（ECM），然后重启。这不是刷固件，也不更改硬件电路。v0.6.0 将这一步加入原生应用，不依赖第三方客户端。

## 开始前

- 使用 Apple Silicon Mac，安装 v0.6.1 或更新版本，将完整应用拖到“应用程序”。更新前正常退出旧版本，替换应用不会删除短信。
- 准备能传输数据的 USB 线，只连接一只 IG830 或 IG832。正常退出其他模块管理软件；出现“允许配件连接”提示时点允许。
- 建议先连接可用 Wi-Fi，因为初始化会短暂断开模块网卡；本操作不会自动改变 Mac 网络优先级。
- **无需 SIM 即可检查与初始化。** 测试联网和短信时需要有效 SIM；装卡前先断开模块 USB，按卡槽标识确认方向并装到位，不能靠反复初始化解决卡片接触问题。

打开应用后，点击菜单栏天线图标 → **新模块初始化…**；也可从“短信与网卡状态…”窗口顶部选择 **初始化**。如果没有这些入口，请先升级应用。应用内同一份分步指引可离线阅读，GitHub 完整文档链接需要联网。

## 第 1 步：检查设备

点击 **检查设备**。应用只查询设备，不修改配置，不发短信；短信后台从此暂停。切换页面不会恢复短信，顶部始终保留“结束初始化并恢复短信”按钮。

| 看到的结果 | 接下来怎么做 |
| --- | --- |
| 出厂模式，可以初始化 | 继续第 2 步 |
| ECM（已配置） | 无需重复写入，直接前往第 3、4 步 |
| 找不到设备或连接多只 | 只保留一只模块，检查数据线及配件权限，退出其他客户端后重试 |
| 型号、固件或 USB 配置不支持 | 停止操作；不要使用其他设备的配置或强行刷机 |

## 第 2 步：备份并启用 ECM

点击 **备份并启用 ECM…**，阅读提示并确认 **备份、启用并重启**。应用先保存原配置并核实备份可读，再修改网络模式。检查未通过或设备已经是 ECM 时，此按钮不可用。

操作处理中保持 USB 连接，不关闭应用。回读网络模式和 USB 组合正确后，应用发送一次重启请求；模块可能先掉线而来不及回复，因此“重启响应未确认”不一定代表写入失败。不要连续重复初始化。

**恢复本机保存的原网络模式…不是初始化的必要步骤。** 它只用于撤销本应用此前对同一设备的网络模式修改，可能使 Mac 不再识别模块网卡。没有匹配的本机备份时，此按钮不可用。

## 第 3 步：重启后复查

待操作结束、模块重新出现，点击 **重新检查设备**（或第 1 步的“检查设备”）。显示 **ECM（已配置）** 才表示配置复查通过，不等于已联网。

如果模块一直未出现，待操作处理结束后断开 USB，等 5 秒再接回；按 macOS 提示允许配件，然后重新检查。若仍不可见，停止重复写入并排查连接。拔插会让旧检查结果失效，必须重新检查。

## 第 4 步：恢复短信并验证可用

1. 点击 **结束初始化并恢复短信**，然后点击 **查看网卡状态**。确认模块网卡出现并有地址；“等待 DHCP”表示地址尚未就绪。
2. 使用有效 SIM 核实实际联网：如需通过模块测试，在网卡页明确选择优先使用 4G，再访问网页；可能需要系统管理员授权、消耗流量。Clash/VPN 或其他网络服务仍可能改变实际出口，网页打开不能单独证明走了 4G。测试后可恢复原优先级。
3. 在短信页给你能确认收件的手机发送一条测试短信，再从手机回复；可能产生套餐费用。“已提交给模块”不是送达证明，需要实际收到。
4. 只用网卡时可以退出应用；接收短信与通知需要应用在后台运行。需要通知时，另外在应用中开启并允许 macOS 通知。

应用不会为你自动发送测试短信、切换出口或启用通知。退出应用不会撤销已写入的 ECM 设置；正常拔插后设置应保留，但其他设备和固件仍需要各自验证。

## 遇到问题怎么办

| 情况 | 建议处理 |
| --- | --- |
| 写入或回读未确认 | 先重新检查真实状态，不自动重试；已是 ECM 时继续复查和使用，需要撤销且存在匹配备份时才选择恢复 |
| 备份损坏或与配置不匹配 | 保留原备份并停止操作，不要删除、覆盖或导入其他设备备份 |
| 已是 ECM，没有恢复按钮 | 这台 Mac 没有由本功能创建的匹配原配置备份；不影响继续使用 ECM |
| ECM 正确，但没有网络 | 查看网卡地址、SIM 是否在手机中可用、信号及套餐；等待 DHCP 不等于已联网，不要靠重复初始化解决运营商问题 |
| 短信一直暂停 | 点击顶部或第 4 步的“结束初始化并恢复短信”；只切换页面不会解除暂停 |
| 固件不支持 | 停止操作；在项目页提供不含隐私的型号、固件和错误提示，等待适配 |

报告问题时不要上传备份、IMEI、SIM 标识、短信内容或未经筛选的日志。

## 边界与保护

仅接受 USB 2ca3:4006、AT 接口 2 / ff:00:00、bulk 0x84 / 0x03，内部型号 QDC507、固件 QDC507GLEFM21。USBCFG 必须匹配已验证组合，允许既有 ADB 位为 0 或 1，但始终保持原值。网络模式只接受 0 或 1。其他型号、固件、组合拒绝写入，不尝试解锁或刷成支持型号。

检查结果只能使用一次。执行前重新枚举并核对端口、注册标识、设备身份、型号/固件与完整配置；中途换设备、拔插、配置变化都要求重新检查。身份查询仅将 IMEI 的 SHA-256 保存在本机，不显示或记录原始 IMEI。

备份位于应用数据目录的 device-setup 下（目录 0700、文件 0600）。备份失败、损坏或与当前配置冲突会停止操作，不覆盖旧备份。不要把备份发到公开 Issue。

## 恢复

只有本机存在属于当前设备、当前固件/USB 组合的原始备份，并且设备当前为 ECM 时，才提供恢复按钮。恢复只将 usbnet 改回记录的出厂网络模式，再回读并重启；Mac 可能因此失去模块网卡。保留最初备份，不能导入其他设备的备份，也不能将它称为完整出厂恢复。

已在其他工具中初始化的两只测试模块没有由本功能创建的出厂备份，因此可检查 ECM，但不会猜测提供恢复。

本功能不改变 ADB 授权、APN、IMS、音频、安装入口盘、固件或开机文件。它不能把未知设备刷成支持全部功能的设备。应用目前支持数据管理与短信，语音尚未实现；安装入口盘临时试验未通过共存验收。

## 验证层级

原生实现已通过模拟事务测试、编译与打包检查；完整新设备初始化、实际恢复与 GUI 仍需实机验收。不能仅凭单元测试承诺其他同型号设备全部可用。

开发诊断可在应用退出后运行 `dist/ModemDiagnostics --inspect-setup`，只读输出支持状态，不输出 IMEI、SIM 或短信；它与应用共用进程锁，不提供命令行写入入口。
