# 新模块初始化

同为 DJI IG830 / IG832，不代表 USB 模式、内部模块或固件一致。已配置为 ECM 的设备在 macOS 允许配件后，可使用系统网卡，不必运行本应用；有效 SIM、运营商配置、信号及路由仍影响联网。

出厂网络模式为 0 的已支持模块需要一次持久配置，将 usbnet 改为 1（ECM），然后重启。这不是刷固件，也不更改硬件电路。v0.6.0 将这一步加入原生应用，不依赖第三方客户端。

## 操作

1. 只连接一只模块，正常退出其他占用模块的客户端。打开“初始化”页或菜单栏“新模块初始化…”。
2. 点击“检查设备”。此时暂停短信，查询型号、固件、设备身份与 USB 配置，不发送短信、不写模块配置；无 SIM 也可以检查。
3. 若显示可初始化，点击“备份并启用 ECM…”，阅读断网/重启提示并确认。应用将原配置保存到本机，核实备份可读后才写入。
4. 回读网络模式和原 USB 组合，匹配后请求重启。模块掉线可能早于重启确认，因此界面区分“已请求”与“响应未确认”，都不宣称设备已恢复。
5. 等待模块回来，重新“检查设备”，到网卡页核实地址，必要时断电重插并允许配件。点击“结束初始化并恢复短信”。互联网与短信仍须各自实测。

初始化过程中切换页面不会自动恢复短信；顶部保留暂停提示和结束按钮。初始化失败、写入超时或重启不确定均不自动重试。退出应用不撤销已写入的网络模式。

## 边界与保护

仅接受 USB 2ca3:4006、AT 接口 2 / ff:00:00、bulk 0x84 / 0x03，内部型号 QDC507、固件 QDC507GLEFM21。USBCFG 必须匹配已验证组合，允许既有 ADB 位为 0 或 1，但始终保持原值。网络模式只接受 0 或 1。其他型号、固件、组合拒绝写入，不尝试解锁或刷成支持型号。

检查结果只能使用一次。执行前重新枚举并核对端口、注册标识、设备身份、型号/固件与完整配置；中途换设备、拔插、配置变化都要求重新检查。身份查询仅将 IMEI 的 SHA-256 保存在本机，不显示或记录原始 IMEI。

备份位于应用数据目录的 device-setup 下（目录 0700、文件 0600）。备份失败、损坏或与当前配置冲突会停止操作，不覆盖旧备份。不要把备份发到公开 Issue。

## 恢复

只有本机存在属于当前设备、当前固件/USB 组合的原始备份，并且设备当前为 ECM 时，才提供恢复按钮。恢复只将 usbnet 改回记录的出厂网络模式，再回读并重启；Mac 可能因此失去模块网卡。保留最初备份，不能导入其他设备的备份，也不能将它称为完整出厂恢复。

已在其他工具中初始化的两只测试模块没有由本功能创建的出厂备份，因此可检查 ECM，但不会猜测提供恢复。

本功能不改变 ADB 授权、APN、IMS、音频、安装入口盘、固件或开机文件。它不能把未知设备刷成支持全部功能的设备。应用目前支持数据管理与短信，语音尚未实现；安装入口盘临时试验未通过共存验收。

## 验证层级

原生实现已通过模拟事务测试、编译与打包检查；完整新设备初始化、实际恢复与 GUI 仍需实机验收。不能仅凭单元测试承诺其他同型号设备全部可用。

开发诊断可在应用退出后运行 `dist/ModemDiagnostics --inspect-setup`，只读输出支持状态，不输出 IMEI、SIM 或短信；它与应用共用进程锁，不提供命令行写入入口。
