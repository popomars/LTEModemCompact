# 使用与故障排查

## 菜单栏与后台

正常启动后，点击菜单栏天线图标，选择“短信与网卡状态…”。关闭窗口后后台继续轮询；“退出 LTEModemCompact”会释放 AT 接口。首次启动不申请通知、不注册登录项。设置中可手动开启，两项都以 macOS 实际批准状态为准。

如只想查看界面，可用下面的演示模式。演示不访问模块、不发送短信，也不申请权限；不能代替真机验收。

```sh
open -n dist/LTEModemCompact.app --args --demo
```

正常数据模式下，`--show` 可在启动时打开主窗口。仅当应用尚未运行时使用；第二个进程会被锁阻止。

## 收发短信

号码只接受数字和开头的 `+`。不带 `+` 使用本地/未知号码类型，显式 `+` 使用国际号码类型。发送前显示分段数并确认，运营商可能按段计费；长文本发送采用 UCS2，单段最多 70 个 BMP 字符，分段后每段最多 67 个，单次最多 10 段。

“已提交给模块”仅表示模块确认，不是送达回执。“结果未知”可能已经发送，请先向收件人核实；程序不会自动重发。

收到短信后选择记录可回复。其他 SIM 的历史、不完整长短信以及来源未核实的旧模块短信不能直接回复。换卡会清除当前撰写框和选择，防止误用旧线路。首次归档既有短信不弹通知，后续完整新短信才进入通知流程。

通知正文不含发送方号码或短信正文；点击查看，展开可快捷回复。快捷回复中的“发送”会真实发送，可能按段计费。通知和快捷回复目前仍需系统实测。

## 常见状态

| 状态 | 处理 |
| --- | --- |
| 等待插入模块 | 检查数据线、USB 接口及配件连接许可 |
| 检测到多个模块 | 暂时只连接一只，避免选错线路 |
| AT 接口被占用或不可访问 | 正常退出其他占用程序；不要同时运行诊断工具和应用 |
| SIM 未就绪 | 断电后按卡槽标识检查方向、接触；需要 PIN 时在支持的设备上解锁 |
| 本地链路已建立但无法联网 | 区分本地 DHCP 与运营商数据；检查 SIM 套餐和网络，不把本地 IP 当成互联网成功 |
| SIM 已更换 | 等待重新识别，再重新确认收件人和内容 |
| 发送结果未知 | 不要立即重发，先核实收件端 |
| 无法保存历史 | 检查磁盘空间和目录访问权限，保留原数据库，不删除以“修复” |

本版本没有自动清理模块存储、修改 APN、开启 IMS、刷固件、拨号或音频初始化功能。模块存储满后可能无法继续接收，请通过你认可的设备管理方式处理；程序不会自行删除内容。

## 诊断

下列第一个命令只读 USB 描述符和系统网络状态，不打开 AT：

```sh
"dist/LTEModemCompact.app/Contents/MacOS/LTEModemCompact" --diagnose
```

正常退出应用后，使用同一个进程锁的诊断工具：

```sh
# 查询型号、SIM 就绪、LTE 注册及 ECM 配置；不读短信
./dist/ModemDiagnostics --probe
# 真实读取短信并归档，只输出状态和计数
./dist/ModemDiagnostics --poll-count 2
```

`--poll-count` 接受 1–60 次，间隔约 4 秒。`--expected-reply-file PATH` 只输出当前 SIM 是否存在完整匹配文本，不打印内容，不证明本次新送达。

`--send-to NUMBER --text-file PATH` 是真实发送入口，只应在明确确认收件人和正文后使用；诊断工具不额外弹出确认。文件内容按原样发送，包括末尾换行。不要把测试正文、收件人或运行日志提交到公开仓库。

诊断只检查当前会话：恢复旧卡、长期离线期间的消息来源、其他固件及其他接口布局可能需要单独核实。先保留证据，不通过重置设备或清空存储掩盖问题。
