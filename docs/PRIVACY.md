# 隐私与数据

## 运行时保存

应用与诊断工具共用 `~/Library/Application Support/NativeModem/`，该旧名称用于兼容更名前的本机数据。

| 数据 | 作用 |
| --- | --- |
| `device-setup/<hash>.json` | 当前模块的原网络模式、USB 组合、型号与固件；IMEI 仅取 SHA-256 作本机备份匹配，不保存原始值，哈希仍属敏感关联数据 |
| `agent.lock` | 防止两个本项目进程同时控制同一模块 |
| `messages-v1.json` | 短信内容、对端号码、时间、原始 PDU、分段、发送状态与本地 SIM 分组 |
| `network-priority-backup.json` | 上次切换前后的网络服务标识和顺序，仅本机保存，用于安全撤销 |
| `network-traffic-v1.json` | 累计收发字节、统计起点及格式版本；不保存访问地址、流量内容、SIM 或接口历史 |
| ICCID 的 SHA-256 | 分卡标识；不保存原 ICCID，哈希仍属于本地敏感关联数据 |
| 插入启动偏好 | 关闭/询问/自动模式，以及系统启动 UUID + 临时 IORegistry ID 用于去重；不保存 USB 序列号 |
| macOS 偏好与系统授权 | 应用身份保持不变，系统负责通知、登录项和权限状态 |

通知正文不包含真实号码、短信正文或验证码；点击提醒可进入应用查看。应用通知开关与提示音偏好存于本机 UserDefaults，macOS 独立管理通知授权与展示。

目录设为 `0700`，短信与流量统计文件原子替换时为 `0600`。文件没有额外应用层加密；同一用户权限的程序仍可能读取，应结合账户访问控制与磁盘加密保护。退出或移除应用不会自动删除历史。

程序没有遥测、云同步、HTTP 服务或外部后端。用户发送的短信仍经 SIM 运营商网络传输；系统 ECM 网卡的互联网流量由 macOS 和用户网络设置管理。

## 消息所有权与失败处理

模块存储可以保留旧卡短信。首次读取模块存储中的未知消息时，不能证明它属于当前 SIM；程序将其标记为归属未核实，禁止直接快捷回复。后续归档使用观测时的 SIM，并在读取前后复核；这不能证明应用未运行期间所有历史消息的实际来源。

发送前记录意图，模块确认后记录提交段数。遇到超时、断线或崩溃时保留不确定状态，不自动重发。原始 PDU 保留以供后续解析，不自动删除模块原文；读取可能将模块的未读标记变为已读。

## 公开仓库边界

只发布 `Sources/`、`Tests/`、`Resources/`、构建与检查脚本以及公共文档。测试夹具为合成号码、合成 SIM 数字和手工组装的 PDU，不来自私人短信。演示 IP 使用文档专用地址。

不发布：

- 真实号码、ICCID、IMSI、IMEI、设备序列号或短信正文。
- 短信数据库、原始 AT 响应、诊断日志、抓包或本地配置备份。
- 个人绝对路径、凭证、签名身份、证书或私钥。
- 预编译应用、临时构建目录、历史本机原型以及相邻第三方源码与运行文件。

`.gitignore` 是第一道防线，发布前还应审查实际暂存内容。`python3 scripts/check-public-source.py` 检查暂存路径与常见敏感模式，不能替代人工审核。

报告问题时优先提供状态文字、错误代码和可重复步骤；不要在公开 Issue 中附短信、SIM 标识或未经筛选的日志。发现疑似泄漏时先停止传播，避免在公开评论重复敏感内容。
